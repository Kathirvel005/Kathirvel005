# Contributing Guidelines

Thank you for your interest in contributing to this profile repository and associated AI projects!

## How to Connect & Collaborate

- **Proposing Improvements:** If you have suggestions for SVG optimization, design refinements, or accessibility enhancements, feel free to open an Issue or pull request.
- **Collaborating on Projects:** For collaboration inquiries on AI models, computer vision systems, or robotics research, please connect via [LinkedIn](https://linkedin.com/in/kathirvel2407) or [Email](mailto:kathirvel2407@gmail.com).

## Guidelines for Pull Requests
1. Ensure all SVGs are valid XML and render properly across both light and dark backgrounds.
2. Maintain high code cleanliness, semantic HTML structure, and mobile readability.
3. Test all links before submitting changes.
