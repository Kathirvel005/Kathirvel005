# Security Policy

## Reporting Security Vulnerabilities

As an AI and software developer, system integrity and responsible disclosure are taken seriously.

If you discover a potential vulnerability, bug, or security concern within this repository or any associated projects:

1. **Do not create a public issue.**
2. Send an email directly to [kathirvel2407@gmail.com](mailto:kathirvel2407@gmail.com) with:
   - Detailed description of the vulnerability
   - Steps or proof of concept to reproduce the issue
   - Potential impact and affected components
3. You will receive an initial response within 48 hours.

Thank you for helping keep the open source ecosystem secure.
